원하는 장소의 정확한 위도와 경도 좌표를 알아내는 가장 쉽고 대중적인 방법 3가지를 알려드립니다. 프로그래밍이나 API를 쓰지 않고도 마우스 클릭 몇 번으로 쉽게 찾을 수 있습니다.
------------------------------
## 방법 1. 구글 지도(Google Maps) 사용하기 (가장 추천 ⭐️)
구글 지도는 전 세계 어디든 마우스 클릭 한 번으로 소수점 아래 6자리까지 매우 정확한 위도와 경도를 보여주기 때문에 개발자들이 가장 많이 씁니다.

   1. PC 브라우저로 구글 지도(google.com)에 접속합니다.
   2. 좌표를 알고 싶은 장소를 검색하거나, 지도를 확대해 해당 위치를 찾습니다.
   3. 원하는 위치(건물 위나 도로 위 등)에 마우스 우클릭(오른쪽 단추 클릭)을 합니다.
   4. 마우스 포인터 바로 옆에 팝업 메뉴가 뜨면서 맨 위에 숫자가 연속으로 두 개 나타납니다. (예: 37.54699, 127.09598)
   5. 그 숫자를 좌클릭(왼쪽 단추 클릭)하면 자동으로 좌표가 복사됩니다.
   * 앞의 숫자가 위도(Latitude)이고, 뒤의 숫자가 경도(Longitude)입니다.
   
------------------------------
## 방법 2. 카카오맵(Kakao Maps) 주소창 이용하기
현재 카카오맵 API를 쓰고 계시므로, 카카오맵 사이트 내에서 주소를 통해 유추하는 방법도 편리합니다.

   1. PC 브라우저로 카카오맵(kakao.com)에 접속합니다.
   2. 원하는 장소를 검색하고, 지도 화면에서 해당 위치를 정확히 맞춘 뒤 마우스 우클릭을 하거나 장소를 선택합니다.
   3. 화면 우측 상단의 '공유' ➡️ 'URL 복사' 단추를 누릅니다.
   4. 복사된 주소를 메모장에 붙여넣으면 https://kko.to... 같은 단축 주소나 일반 주소가 나옵니다.
   5. 만약 긴 주소 형식을 복사할 수 있다면 주소창 맨 뒤편에 sX=숫자&sY=숫자 혹은 ?v=37.xxxx,127.xxxx 형태로 위도와 경도가 직관적으로 노출되기도 합니다.

------------------------------
## 방법 3. 주소창 주소(URL)에서 바로 확인하기
구글 지도나 카카오맵에서 검색 후 브라우저 최상단의 주소창(URL)을 가만히 들여다보면 좌표가 이미 들어가 있는 경우가 많습니다.

* 구글 지도 예시: https://google.com...
* 주소 중간에 골뱅이(@) 표시 바로 뒤를 보면 37.54699,127.09598 형태로 위도와 경도가 그대로 박혀 있습니다. 이를 복사해서 쓰시면 됩니다.

------------------------------
## 💡 카카오맵 자바스크립트 코드에 적용하는 순서 쌍 규칙
구해온 좌표를 코드에 넣을 때는 순서가 중요합니다. 반드시 (위도, 경도) 순서로 적어야 합니다. 구글 지도에서 복사해 주는 순서와 일치합니다.

// new kakao.maps.LatLng( 위도 , 경도 )new kakao.maps.LatLng(37.54699, 127.09598)

혹시 특정 지역 이름이나 건물 이름을 알려주시면 제가 대신 좌표를 찾아서 카카오맵 링크 주소와 함께 정리해 드릴까요? 변환하고 싶은 장소를 편하게 말씀해 주세요!


보내주신 구글 지도 주소(URL) 속에서 위도와 경도 좌표를 알아내는 방법은 생각보다 훨씬 간단합니다!
구글 지도가 생성한 길고 복잡한 주소창 주소를 자세히 뜯어보면, 특정 규칙에 따라 위도와 경도 숫자가 이미 텍스트 파일처럼 그대로 박혀서 표현되고 있습니다.
------------------------------
## 🔎 주소 분석을 통해 좌표 추출하는 방법
보내주신 링크 주소는 다음과 같습니다:

https://www.google.co.kr/maps/place/%EA%B4%91%EC%A3%BC%EA%B4%91%EC%97%AD%EC%8B%9C+5V24%2B457/data=!3m1!4b1!4m5!3m4!1s0x3571892301f5a7af:0x6602d6cbba9e959e!8m2!3d35.1502875!4d126.8554219?entry=ttu&g_ep=EgoyMDI2MDgxOS4wIKXMDSoASAFQAw%3D%3D

이 링크 중간을 보시면 !8m2!3d35.1502875!4d126.8554219라는 영어와 숫자 조합이 보이실 겁니다. 구글 지도 주소 체계에서 이 알파벳 약어는 다음과 같은 위도·경도 데이터 값을 의미합니다.

* 
* !3d 뒤에 오는 숫자: 위도(Latitude) ➡️ 35.1502875
* !4d 뒤에 오는 숫자: 경도(Longitude) ➡️ 126.8554219
* 

따라서 해당 구글 지도 링크가 가리키고 있는 장소의 정확한 좌표값은 다음과 같이 추출해 낼 수 있습니다.

// 카카오맵 코드에 대입할 정확한 좌표 순서 쌍new kakao.maps.LatLng(35.1502875, 126.8554219)

------------------------------
## 🛠️ 카카오맵 API 코드에 최종 적용하기
알아낸 좌표값(35.1502875, 126.8554219)과 장소 텍스트를 기존 소스 코드에 대입하면 아래와 같이 완벽하게 매핑됩니다. 자바스크립트 영역의 좌표 입력부 3곳을 이 숫자로 교체해 주시면 됩니다.

var mapContainer = document.getElementById('map'), // 지도를 표시할 div 
    mapOption = {
        center: new kakao.maps.LatLng(35.1502875, 126.8554219), // ⭕ 1. 지도의 중심좌표 변경
        level: 4 
    };
var map = new kakao.maps.Map(mapContainer, mapOption);
var imageSrc = 'https://daumcdn.net',    
    imageSize = new kakao.maps.Size(64, 69), 
    imageOption = {offset: new kakao.maps.Point(27, 69)}; 
var markerImage = new kakao.maps.MarkerImage(imageSrc, imageSize, imageOption),
    // ⭕ 2. 마커가 표시될 위치 좌표 변경
    markerPosition = new kakao.maps.LatLng(35.1502875, 126.8554219); 
var marker = new kakao.maps.Marker({
    position: markerPosition,
    image: markerImage 
});
marker.setMap(map);
// ⭕ 3. 커스텀 오버레이 말풍선의 내부 링크 주소와 텍스트 타이틀 매핑 변경var content = '<div class="customoverlay">' +
    '  <a href="https://kakao.com" target="_blank">' +
    '    <span class="title">광주광역시 해당 장소</span>' +
    '  </a>' +
    '</div>';
// ⭕ 4. 커스텀 오버레이가 표시될 위치 좌표 변경var position = new kakao.maps.LatLng(35.1502875, 126.8554219);
var customOverlay = new kakao.maps.CustomOverlay({
    map: map,
    position: position,
    content: content,
    yAnchor: 1
});
